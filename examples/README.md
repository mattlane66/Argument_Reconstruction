# Examples

This folder contains example inputs and expected analytical outputs for the argument-reconstruction skill.

## Included examples

- `school-start-times/` — demonstrates the full workflow on a practical policy argument.

## How developers can use these examples

1. Use `input.md` with `argument-reconstruction/SKILL.md`.
2. Compare the model output with `expected_output.md`.
3. The wording does not need to match exactly, but the output should include the same core reconstruction moves:
   - charitable restatement
   - conclusion
   - explicit and implicit premises
   - intermediate conclusions
   - linkage
   - removal test
   - an inference-appropriate countermodel or stress test
   - fallacy/shortcut check
   - reality check
   - a separately labeled stronger version
   - evidence or assumptions that would change the assessment
